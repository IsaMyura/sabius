# Sabius 🎓✨

O **Sabius** é uma plataforma de estudos inteligente desenvolvida como projeto de conclusão de curso (TCC). O objetivo do sistema é auxiliar estudantes integrando funcionalidades de organização de conteúdo e inteligência artificial para otimizar o aprendizado.

## 🚀 Funcionalidades Principais
- **Resumos Automatizados:** Geração de resumos de matérias de forma rápida.
- **Quizzes com Diagnósticos:** Testes para avaliar o conhecimento do usuário com feedbacks baseados nos erros e acertos de cada assunto e matéria.
- **Chat Sabius:** Um chat integrado com Inteligência Artificial para tirar dúvidas e explicar conceitos em tempo real.

## 🛠️ Tecnologias Utilizadas
- **Backend:** Python
- **Frontend:** HTML, CSS, JavaScript
- **IA:** Integração com API de Inteligência Artificial *(OpenAI)*
